# AutoCAD Project 1 — 2D Residential Floor Plan

Part of the DecodeLabs AutoCAD Industrial Training Kit (Batch 2026).

A precise, industry-standard 2D floor plan for a modern single-family home,
drafted with strict layer management, standard blocks, and accurate dimensioning.

---

## Objective
Translate an architectural concept into a precise, actionable 2D blueprint —
demonstrating structural precision, disciplined layer architecture, and
standards-compliant dimensioning.

## Key Requirements Implemented
- **Layer Management** — a strict layer system separating Walls, Doors,
  Windows, and Electrical, each with its own color and lineweight.
- **Blocks** — standard reusable blocks for furniture and fixtures.
- **Dimensioning & Annotations** — accurate dimensions and text annotations
  throughout the plan.

## Key Skills Demonstrated
2D Drafting · Layer Architecture · Block Management · Dimensioning Standards
